# Sistema de Login com CustomTkinter

Este projeto é um **sistema simples de login com interface gráfica**, desenvolvido em **Python** utilizando a biblioteca **CustomTkinter**. O objetivo é praticar conceitos de interface gráfica, lógica de autenticação e manipulação de eventos.

## 🖥️ Funcionalidades
- Tela gráfica de login
- Campo para e-mail e senha
- Opção de **mostrar/ocultar senha**
- Validação de login e senha
- Exibição de mensagens de erro e sucesso
- Abertura de um arquivo HTML após login válido
- Botão de cadastro (estrutura inicial)

## 🛠️ Tecnologias Utilizadas
- Python 3
- CustomTkinter
- Tkinter (messagebox)
- OS (para abertura de arquivos)
